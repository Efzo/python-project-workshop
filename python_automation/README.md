# Python Automation

Start with [Project 1 — Folder inventory](project_1/README.md). Run each lesson's commands from this `python_automation` folder with Python 3.11 or later. Every script uses the standard library. The sample inputs are disposable, and the lessons that produce files use an ignored `output/` folder.

| Project | Build | Practice |
| --- | --- | --- |
| [1](project_1/README.md) | Folder inventory | Paths, arguments and file inspection |
| [2](project_2/README.md) | File organizer | Dry runs, copying and repeat-safe writes |
| [3](project_3/README.md) | Order reporter | CSV validation, aggregation, JSON and exit codes |
| [4](project_4/README.md) | Stock feed checker | HTTP, timeouts, backoff and retry limits |
| [5](project_5/README.md) | ZIP backup | Recursive paths, archives and SHA-256 |
| [6](project_6/README.md) | Daily sales pipeline | Logging, database upserts, atomic reports and scheduling |

By the end, you should be able to take a repetitive process, spell out its inputs and outputs, automate it, and show how it behaves with invalid inputs and repeated runs.
