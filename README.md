# Python project-based learning

Every track starts at `project_1` and includes source code, a walkthrough, sample commands, and exercises with acceptance checks. Use Python 3.11 or later.

| Track | Start here | Projects |
| --- | --- | --- |
| [Python Fundamentals](python_fundamentals/README.md) | [Quiz game](python_fundamentals/project_1/README.md) | 9 |
| [Python Automation](python_automation/README.md) | [Folder inventory](python_automation/project_1/README.md) | 6 |
| [FastAPI](fastapi/README.md) | [First API](fastapi/project_1/README.md) | 6 |
| [Agentic AI](agentic_ai/README.md) | [Structured request classifier](agentic_ai/project_1/README.md) | 6 |

If Python is new to you, begin with Fundamentals. Automation starts with small scripts and uses material from the first three Fundamentals projects. FastAPI builds on functions, type hints, JSON, and SQLite. Agentic AI uses the same Python foundations and introduces agents, one capability at a time.

For each project, run the example, trace how the input becomes output, and then complete an exercise from a blank file or a copy you can experiment with.
